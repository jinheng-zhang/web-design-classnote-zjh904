Superpowers 给 Trae IDE 安装工作规范

一套软件工程规范技能集（Skills），给 AI 编码加上强制开发流程：需求澄清 → 方案设计 → 任务拆解 → TDD 编码 → 代码评审 → 分支收尾

约 10 分钟 · 5 步安装 + 6 阶段工作规范

准备工作 开始前请确认这两项已就绪

🖥️

Trae IDE

电脑安装好 Trae IDE，能正常打开并联网。

🔧

Git 已配置

已安装 Git，并配置好用户名邮箱。在终端运行以下命令检查：

git config --global --list
📁

创建项目文件夹

新建一个 纯英文、无空格、无中文 的空文件夹，用 Trae 打开它，并打开内置终端。

五步安装流程 跟着下面的步骤，一行一行敲

1

拉取 Superpowers 源码仓库 GitHub Clone

创建本地 superpowers 存放目录，并克隆官方仓库。

# 1. 创建本地目录（已存在则跳过不报错）
mkdir ~/.trae/superpowers -Force
cd ~/.trae/superpowers

# 2. 克隆官方仓库
git clone https://github.com/ice-zjchen/superpowers.git .
终端无红色报错，提示 clone 成功即通过。
2

创建 Trae 技能目录

为 Trae 预留存放 Skills 的目录。

mkdir ~/.trae/skills -Force
3

在项目内创建工作规范配置文件 核心！

这是关键的一步，让你的项目加载 Superpowers 规范。

在你自己的 项目根目录 中操作（不是 ~/.trae）：
① 新建文件夹：.trae/rules/
② 在 .trae/rules/ 里新建文件：superpowers.md
③ 把下面内容整段粘贴进去保存 
## Superpowers System
<EXTREMELY_IMPORTANT>
You have superpowers. Superpowers teach you new skills
and capabilities. RIGHT NOW run:
`~/.trae/superpowers/.trae/superpowers-trae bootstrap`
and follow the instructions it returns.
</EXTREMELY_IMPORTANT>
4

Bootstrap 引导加载技能 激活

运行 bootstrap 脚本，让整套开发工作规范生效。

cd ~/.trae/superpowers
node .trae/superpowers-trae bootstrap
5

重启 Trae 会话，测试是否生效 验证

关掉所有旧的对话窗口，新建一个聊天会话，输入以下测试指令：

你是否加载了 Superpowers？
请列出你启用的工作规范技能。
AI 回复已加载 Superpowers，并列出 14 个软件工程技能 → 安装成功！

六阶段前端工程规范 整段复制，在 Trae 新会话里粘贴即可启用

从现在启用适配《高级网页设计》课程的 Superpowers 前端工程规范，全程严格遵守，禁止跳过阶段：

1. Brainstorming 需求研讨：在编写任何 HTML/CSS/JS 代码前，先和我沟通需求，主动提问确认功能边界、交互细节、页面样式、浏览器兼容范围；输出 spec.md 需求规格文档。必须等待我确认需求文档，才可以进入任务拆解阶段，禁止直接生成代码。

2. writing-plans 任务拆解：基于 spec.md，把项目拆分成多个小型、可独立验证的开发任务，每个任务附带清晰验收标准。任务粒度要适合前端网页开发，一次只推进一个任务，等待我确认任务清单后再开始编码。

3. TDD 前端测试先行：每个开发任务，先写出人工功能验收清单（前端网页以手动测试为主，不强制复杂单元测试），再编写 HTML/CSS/JS 实现功能。验收清单要写清楚：如何在浏览器验证该任务是否完成。

4. Code-review 前端代码评审：单个任务代码完成后，执行前端专项代码审查：变量命名、代码可读性、JS 事件机制、事件冒泡、绑定合理性、CSS 冗余、Flex/Grid 布局规范性、代码可维护性；输出评审报告，存在问题需要修改完善。

5. Manual Verification 人工页面验证：代码生成后，提醒我把代码保存到本地文件，在浏览器打开网页，按照验收清单手动测试功能，测试通过后再进入下一个任务。

6. Git 版本管理与项目收尾：全部任务开发完成后，指导我执行 Git 分阶段提交，最后输出 retrospective.md 项目复盘文档。

请回复：课程版 Superpowers 前端工程规范已启用，请输入项目需求。
⚠️ 三个致命坑，务必避开
  • ❌ 不新建会话：安装完 Superpowers，旧对话不会加载规范，必须新建 Trae 会话！
  • ❌ 跳过 brainstorming：直接让 AI 写代码，Superpowers 会拒绝执行，强制先完成需求文档。
  • ❌ 项目目录带中文/空格：会导致 bootstrap 脚本路径报错，请用纯英文路径。
使用提示：课堂演示时建议同步终端操作，让同学跟着逐行敲。
