任务二 · creative 电影墙

课堂讲了 fade、cube、coverflow、flip、cards 这几种 effect，缺的第七种是 creative。 这一关把它做成电影墙：上一张缩小、左移、带角度退场，下一张放大、从右侧进场。

① 新增第 7 个按钮② 上一张缩小左移带角度③ 下一张放大右移进场④ 讲清 prev / next
要求：在演示台里加上第 7 个按钮「creative 电影墙」，点它能把轮播切成电影墙效果； 需要向 AI 追问 prev / next 的参数含义，最终能用自己的话说清楚百分号相对谁计算。

prev / next 参数各 6 个，合起来管一退一进

✅ 已落地
参数类型作用
translate[x, y, z]位移。x / y 可写百分比字符串或 px 数字，z 只能写 px
rotate[x, y, z]三轴旋转，单位度；第三个值才是画面里的平面旋转
scalenumber缩放倍数，小于 1 缩小、大于 1 放大
opacitynumber透明度，0 全透明、1 不透明
shadowboolean是否给幻灯片加投影
originstring变换原点，例如 'right center' 表示以右边缘为中心缩放
creativeEffect: { prev: { // 左边退场的那张 shadow: true, translate: ['-22%', 0, -140], // 左移自身宽 22%，后退 140px scale: 0.78, // 缩小到 0.78 倍 rotate: [0, 0, -8], // 平面倾斜 8 度 opacity: 0.75, origin: 'right center' }, next: { // 右边进场的那张 shadow: false, translate: ['100%', 0, 0], // 从自身宽度 100% 处推入 scale: 1.12, // 放大到 1.12 倍 opacity: 1, origin: 'left center' }, limitProgress: 1, perspective: true }

代码解析creativeEffect 每个参数在源码里怎么走

✅ 对照 effect-creative.mjs

下面逐行解释我们电影墙配置的每一个参数，以及它在 Swiper 源码里是怎么被处理的。

/* === creativeEffect 整体结构 === */ creativeEffect: { prev: { shadow, translate, scale, rotate, opacity, origin }, // 左边退场的那张 next: { shadow, translate, scale, rotate, opacity, origin }, // 右边进场的那张 limitProgress: 1, // 只管紧邻的 1 张，数值是"作用范围" perspective: true // 打开 3D 透视，z 轴位移才有纵深感 } /* === 我们的电影墙配置逐行注释 === */ creativeEffect: { prev: { shadow: true, // 给左边这张加投影，通过 boxShadow 样式实现 translate: ['-22%', 0, -140], // getTranslateValue() 原样透传字符串 → 写进 style.transform // x=-22%（相对 slide 自身宽度左移）、y=0、z=-140px（往后退） scale: 0.78, // translate3d 里的 scale，直接写进 transform rotate: [0, 0, -8], // rotate3d(0, 0, 1, -8deg)，Z 轴平面倾斜 -8° opacity: 0.75, // 直接写进 style.opacity origin: 'right center' // 写进 style.transform-origin，以右边缘为基准缩放 }, next: { shadow: false, // 右边这张不加阴影（刚进场时阴影不明显） translate: ['100%', 0, 0], // 从 slide 自身宽度的 100% 处推入，正好在画面外 scale: 1.12, // 进场时比实际大一点，有"迎面推过来"的感觉 opacity: 1, // 完全不透明 origin: 'left center' // 以左边缘为基准缩放，从画面外推进来时锚点在左 }, limitProgress: 1, perspective: true } /* === 源码里关键函数（取自 effect-creative.mjs） === */ function getTranslateValue(value) { if (typeof value === 'string') return value; // ← 这就是为什么百分比相对 slide 自身！ return `${value}px`; // 字符串直接透传给 CSS transform } // ... 最后 targetEl.style.transform = transform; // targetEl = slide 本身
我们写的配置源码里怎么处理浏览器里的效果
prev.translate: ['-22%', 0, -140]字符串 '-22%' 被原样透传给 style.transform左边这张往左移自身宽度 22%，并后退 140px
prev.scale: 0.78直接写进 translate3d(0,0,0) scale(0.78)缩小到 0.78 倍
prev.rotate: [0,0,-8]写进 rotate3d(0,0,1,-8deg)平面倾斜 -8°
next.translate: ['100%',0,0]字符串 '100%' 原样透传下一张从画面右侧一整张宽度外推进来
origin: 'left center'写进 style.transformOrigin变换以左边缘为基准

两轮提示词先问参数，再追问参照物

✅ 源码核实

提示词 A · 问参数 📄 zjh_prompt.md GitHub ↗

我要给 Swiper 轮播加一个课堂没讲的第 7 种效果 creative（自定义变换）。请打开官方示例 swiper/demo/257-effect-creative.html，读懂 creativeEffect，回答我三件事： 1. creativeEffect 里 prev 和 next 各自能写哪些参数？分别控制什么？ 2. translate 数组的三个值 [x, y, z] 单位分别是什么？百分比是相对哪个元素算的？ 3. 怎样实现"上一张缩小左移并带角度、下一张放大右移进场"这种电影墙效果？给我一段可直接用的配置。
AI 回答：给了 6 个参数（见上表）和一版配置，但没说明百分比相对谁计算。 对照本地 types/modules/effect-creative.d.ts 核对，参数名都对。

提示词 B · 追问参照物 📄 zjh_prompt.md GitHub ↗

你说 translate 用百分比，那这个百分比到底是相对【幻灯片自己】还是相对【外层容器】算的？ 我本地已经装了 swiper 11.0.3 源码，请直接在 swiper/modules/effect-creative.mjs 里 找到给 slide 写 transform 的那段代码，用源码回答我；然后按"上一张缩小左移带角度、 下一张放大右移进场"给我最终配置。
AI 回答：源码里 getTranslateValue() 对字符串原样透传给 style.transform， 而 transform 写在幻灯片自己身上，所以百分比相对幻灯片自身的宽度计算。 这也解释了为什么 '100%' 正好能把下一张推到画面外。
5

答辩两问用自己的话，不看稿

✅ 已准备

Q1 · prev 和 next 各控制什么？

prev 管左边那张正在退场的，next 管右边那张正在进场的。一个往后退、一个往前推， 合起来才有纵深。我的写法是左边缩小到 0.78、左移 22%、后退 140px、倾斜 8°， 右边从 100% 处推入并放大到 1.12 倍。

Q2 · 百分号相对谁？改成转 20 度怎么写？

相对幻灯片自己的宽度，不是外层容器，所以 '-22%' 是这张图自身宽度的 22%。 想转 20 度就把 rotate 的第三个值改成 [0, 0, 20]，第三位才控制平面旋转。
