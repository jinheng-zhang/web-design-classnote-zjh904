Lucide · SVG Icon Method

矢量图标 · 标本

Lucide 通过脚本将 <i data-lucide="name"> 替换为内联 <svg>。每个图标都是可缩放矢量，可用 stroke-width、width/height 与 CSS 颜色精细控制。

data-lucide="plane"
24×24 viewBox · 1.5px 默认描边 · currentColor 填充
data-lucide="heart"
内联 SVG · 描边可随 CSS 颜色变化
data-lucide="github"
品牌图标 · 单 path 矢量描边
