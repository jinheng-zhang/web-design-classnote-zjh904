四个模块的参数只列关键项

✅ 已落地
模块关键参数作用
keyboardenabled: true
onlyInViewport: true
pageUpDown: true		方向键、PageUp/PageDown 翻页；只在轮播进入视口时响应，输入框里打字不受影响
mousewheelenabled: true
sensitivity: 0.85
thresholdDelta: 25		滚轮翻页；数值越大越灵敏；releaseOnEdges 让首尾处把滚动交还页面
zoommaxRatio: 2.6
toggle: false		双击放大到 2.6 倍；图片必须放在 .swiper-zoom-container 里
parallaxparallax: true
data-swiper-parallax="-180"		开启后，带 data 属性的子元素在翻页时按比例错位，产生纵深

提示词向 AI 请教没讲过的 keyboard

✅ 已修正

提示词 📄 zjh_prompt.md GitHub ↗

在 Swiper 轮播上再加一个【课堂没讲过】的能力，我选 keyboard 键盘控制。 请告诉我 keyboard 参数该怎么写、默认行为是什么、以及有没有什么坑 （比如会不会影响我在输入框里打字）。
AI 第一次的错：写成 keyboard: true，Swiper 实际要求对象 { enabled: true }；另外把参数 onlyInViewport 写成了不存在的 onlyInBrowser。对照本地 swiper/modules/keyboard.mjs 才改对。
另一个坑：zoom 默认 toggle: true，会自己响应双击， 和我写的 dblclick 各放大一次、互相抵消，看起来像没反应，所以配置里关掉它。

答辩四连问每题两三句话

✅ 已准备

Q1 · 这段代码在做什么？

一个实例上挂了四个模块：keyboard 监听键盘事件，mousewheel 把滚轮转成翻页， zoom 处理双击缩放的指针手势，parallax 在翻页过程中按比例位移字幕。 图片包在 .swiper-zoom-container 里，zoom 才能找到缩放对象。

Q2 · AI 第一次错在哪？

把 keyboard 写成布尔值 keyboard: true，还编了一个不存在的参数 onlyInBrowser。 按源码改成 { enabled: true, onlyInViewport: true } 才生效。

Q3 · zoom 里的 toggle: false 起什么作用？

zoom 模块默认开启 toggle，会自己响应双击；我另外写了 dblclick 再 toggle 一次， 两次互相抵消。设成 false 后，双击只由我的 dblclick 处理，放大和还原都正常。

Q4 · 把 thresholdDelta 改成 10 会怎样？

阈值变小，滚轮更容易触发翻页，轻轻滚一下就会换张，灵敏但容易误触。 反过来调大，就必须多滚几下才翻一页。
