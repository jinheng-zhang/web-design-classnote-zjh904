/* 先初始化缩略图实例 */ var zjh_thumbs = new Swiper('#zjhThumbs', { loop: true, spaceBetween: 8, slidesPerView: 4.5, freeMode: true, // 自由模式，缩略图可以停下一半 watchSlidesProgress: true // 跟踪进度，主图当前页对应高亮缩略图 }); /* 再初始化主图实例，thumbs 里引用缩略图 */ var zjh_swDemo = new Swiper('#zjhSwDemo', { loop: true, speed: 750, keyboard: { enabled: true, onlyInViewport: true, pageUpDown: true }, mousewheel: { enabled: true, sensitivity: 0.85, thresholdDelta: 25, releaseOnEdges: true }, zoom: { maxRatio: 2.6, minRatio: 1, toggle: false }, parallax: true, pagination: { el: '#zjhPagDemo', clickable: true }, navigation: { nextEl: '#zjhNextDemo', prevEl: '#zjhPrevDemo' }, thumbs: { swiper: zjh_thumbs } // 绑定缩略图库 });

提示词向 AI 请教没讲过的 keyboard + thumbs

✅ 已修正

提示词 📄 zjh_prompt.md GitHub ↗

任务三给我新增 swiper 的缩略图轮播（thumbs gallery），以及上下翻转（vertical 方向）。 demo 就在本目录 swiper/demo/ 里找一个最合适的。
AI 第一次的错： ① 把 keyboard 写成 true（布尔），实际要对象 { enabled: true, onlyInViewport: true }；
② 编了一个不存在的参数名 onlyInBrowser，正确的是 onlyInViewport；
③ thumbs 里让主图先初始化，缩略图后初始化——但 Swiper 要求 thumbs 实例 在主图之前 new，否则 thumbs: { swiper: xxx } 引用不到。
另一个坑：zoom 默认 toggle: true 会自己响应双击， 和我写的 dblclick 互相抵消，所以关掉它。

答辩五连问每题两三句话

✅ 已准备

Q1 · 这段代码在做什么？

两个 Swiper 实例：主图实例挂 keyboard / mousewheel / zoom / parallax / thumbs / pagination / navigation， 缩略图实例配 freeMode + watchSlidesProgress， 主图通过 thumbs: { swiper: zjh_thumbs } 绑定，两个实例靠 slideChange 双向同步。

Q2 · AI 第一次错在哪？

三个：keyboard 写成布尔、编了不存在的参数 onlyInBrowser、thumbs 实例初始化顺序搞反了。 按本地源码 keyboard.mjs 的 extendParams 和官方 demo 310-thumbs-gallery-loop.html 改对。

Q3 · thumbs 实例为什么要先 new？

主图配置里的 thumbs: { swiper: zjh_thumbs } 传的是实例引用， 如果主图先初始化，zjh_thumbs 变量还没赋值就是 undefined，thumbs 模块拿不到实例就不联动。

Q4 · zoom 里的 toggle: false 起什么作用？

zoom 模块默认开启 toggle，会自己响应双击；我另外写了 dblclick 再 toggle 一次， 两次互相抵消。设成 false 后，双击只由我的 dblclick 处理。

Q5 · 把 thresholdDelta 改成 10 会怎样？

阈值变小，滚轮更容易触发翻页，灵敏但容易误触；改成 80 就必须多滚几下才翻一页。
