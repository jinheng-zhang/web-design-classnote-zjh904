两轮提示词第 1 轮直译需求，第 2 轮补参数名

✅ 2 → 4 项

第 1 轮提示词 📄 zjh_prompt.md GitHub ↗

用 JavaScript + Swiper 11 写一个轮播初始化配置 new Swiper('#zjhSw4', {...})，要求： 1. 无缝循环播放 2. 每 3.2 秒自动翻页 3. 底部有圆点分页器 4. 初始切换效果是 cube（3D 立方体）
AI 回答： new Swiper('#zjhSw4', { loop: true, effect: 'cube', speed: 800, autoplay: { delay: 3200 }, pagination: { el: '#zjhPag4' } })
核对后有两处漏项：缺少 disableOnInteraction: false， 拖动后自动播放会停；缺少 clickable: true，圆点点不动。

第 2 轮提示词 📄 zjh_prompt.md GitHub ↗

在上一版基础上补两条硬性要求： 1. autoplay 里加 disableOnInteraction: false，用户手动滑动之后自动播放继续； 2. pagination 里加 clickable: true，圆点可点击直接跳到对应图片。 另外请把完整的 new Swiper('#zjhSw4', {...}) 代码原样给我，并用一句话说明每项配置的作用，我要直接粘进页面验证。
AI 回答：两条都补上了，并逐条解释了每个参数的作用。落地到本页的代码：
new Swiper('#zjhSw4', { loop: true, // 无缝循环 speed: 800, // 切换动画时长（毫秒） effect: 'cube', // 初始效果：3D 立方体 autoplay: { delay: 3200, // 每张停留 3.2 秒 disableOnInteraction: false // 手动操作后继续播放 }, pagination: { el: '#zjhPag4', // 圆点容器 clickable: true // 圆点可点击跳转 } });

✅ 4 / 4
需求实测值结论
① 无缝循环loop = true翻过第 5 张继续走，能回到第 1 张。
② 3.2 秒自动翻页，手动后不停delay = 3200
disableOnInteraction = false		静止约 3.2 秒自动翻一张；拖动松开后继续翻。
③ 圆点可点击clickable = true
圆点 5 个		点第 4 个圆点直接跳到第 4 张。
④ 初始 cubeeffect = 'cube'打开页面就是立方体翻转。

一句话结论

第 1 轮的问题不是语法错，而是需求里的限定词没写成参数名：手动后不停 → disableOnInteraction: false， 圆点可点击 → clickable: true。第 2 轮直接把参数名写进提示词，一次改对。
