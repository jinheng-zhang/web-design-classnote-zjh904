本次实践说明

1. 选项卡文案与版式按截图复刻，默认选中「主编推荐」；左栏力荐书目、中栏封面价格网格、右栏榜单为固定栏。

2. 切换逻辑不写进页面，单独放在 JS/tab-904.js，本页用 script 标签外部引用后调用 zjh_initTabs()。

3. 事件在选项卡容器上以事件委托监听一次 click；切换时先循环清除全部选中态、隐藏全部面板，再设置当前元素选中并显示对应面板。

4. 所有 CSS 类名与 JavaScript 变量统一以 zjh_ 开头，封面图片取自项目 img 文件夹。
