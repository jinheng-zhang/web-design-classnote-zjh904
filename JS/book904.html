本次实践说明

实践目标
用原生 HTML、CSS、JavaScript 做出四分类的 Tab 选项卡：默认选中"小说"，点击分类名切换书架上展示的书目，封面图片取自项目 img 文件夹。
外部引用
选项卡逻辑不写在页面里，单独放在 JS/tab-904.js，本页用 <script src="tab-904.js"> 引入后调用 zjh_initTabs() 完成初始化；页面只保留结构与样式。
可复用
组件通过 data-tab 与 data-panel 属性匹配选项卡与内容面板，选择器、类名、回调都可用配置对象改写；新闻频道页与本页共用同一份 JS，无需复制代码。
事件监听
在选项卡容器上只监听一次 click，用事件委托从被点击节点向上查找最近的选项卡，取 data-tab 值后切换，动态新增的选项卡也自动生效。
切换逻辑
切换时先循环清除所有选项卡的选中状态、隐藏所有面板，再单独为当前元素设置选中态并显示对应面板，保证任意时刻只有一个分类处于选中与显示状态。
命名约定
所有 CSS 类名、id 与 JavaScript 变量统一以 zjh_ 开头，避免与页面其他样式冲突。
无障碍
选项卡使用 role="tab"、aria-selected 与 tabindex 同步状态，面板补 hidden 属性；保留可见的键盘焦点样式，并响应 prefers-reduced-motion。
