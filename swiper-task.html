下面摘录三大课堂进阶任务的关键提示词原文与AI 回答要点，作为"能讲清"的答辩证据链。

任务一 · 提示词工程师：让 AI 听懂需求✅ 迭代 2 轮通过

▎第 1 轮提示词（原始需求直译版）用 JavaScript + Swiper 11 写一个轮播初始化配置 new Swiper('#zjhSw4', {...})，要求： 1. 无缝循环播放 2. 每 3.2 秒自动翻页 3. 底部有圆点分页器 4. 初始切换效果是 cube（3D 立方体）
AI 第 1 轮回答要点：给了 loop:true、autoplay:{delay:3200}、 pagination:{el:'#zjhPag4'}、effect:'cube'。
我的核对发现两处漏项：① 缺 autoplay.disableOnInteraction:false（手动操作后不停）； ② 缺 pagination.clickable:true（圆点可点击）。
▎第 2 轮提示词（点名参数 + 要求可粘即用）在上一版基础上补两条硬性要求： 1. autoplay 里加 disableOnInteraction: false，用户手动滑动之后自动播放继续； 2. pagination 里加 clickable: true，圆点可点击直接跳到对应图片。 另外请把完整的 new Swiper('#zjhSw4', {...}) 代码原样给我。
AI 第 2 轮回答要点：补齐了全部参数，逐行解释了每项配置的作用。
验证结果：控制台读取 loop=true、autoplay.delay=3200、 disableOnInteraction=false、clickable=true、effect='cube'，四项需求全部命中。

任务二 · creative 仿写：课堂没讲，AI 教你✅ 第 7 效果已上线

▎提示词 A（向 AI 请教未讲过的 API）我要给 Swiper 轮播加一个课堂没讲的第 7 种效果 creative（自定义变换）。请打开官方示例 swiper/demo/257-effect-creative.html，读懂 creativeEffect，回答我三件事： 1. prev 和 next 各自能写哪些参数？分别控制什么？ 2. translate 数组的三个值 [x, y, z] 单位分别是什么？百分比是相对哪个元素算的？ 3. 怎样实现"上一张缩小左移并带角度、下一张放大右移进场"这种电影墙效果？给我一段可直接用的配置。
▎提示词 B（追问：百分比的参照物）你说 translate 用百分比，那这个百分比到底是相对幻灯片自己还是相对外层容器算的？请直接在 swiper/modules/effect-creative.mjs 里找到给 slide 写 transform 的那段代码，用源码回答我。
AI 回答要点（源码佐证）：源码 effect-creative.mjs 中 getTranslateValue() 对字符串原样透传， 最终 transform 写在幻灯片元素本身上，因此百分比相对该张幻灯片自身解析。
我落地的电影墙配置：prev 向左推 -22% + 后退 140px + 缩到 0.78 倍 + Z 轴 -8 度，next 从右 100% 处推入 + 放大到 1.12 倍。

任务三 · 综合创作 + 技术答辩✅ 新展品 + 键盘控制

▎提示词 A（生成第六件展品图片）帮我生成一张横版 16:9 的图片：大型豪华邮轮「爱达·魔都号」航行在蔚蓝海面上的英雄镜头。主体是一艘白色与深蓝涂装的现代大型邮轮……整体为高质感写实摄影风格……无任何文字、logo、水印。
▎提示词 B（超纲能力：键盘控制）在 Swiper 轮播上再加一个课堂没讲过的能力，我选 keyboard 键盘控制。请告诉我 keyboard 参数该怎么写、默认行为是什么、以及有没有什么坑（比如会不会影响我在输入框里打字）。
AI 回答要点：keyboard: { enabled: true } 即可开启，onlyInBrowser: true 限定只在真实浏览器窗口生效。
我采纳并补全：加上了 onlyInBrowser: true，避免在编辑器环境误触方向键翻页。
最终落地：keyboard: { enabled: true, onlyInBrowser: true }，按 ← → 可翻页且不影响页面滚动。
